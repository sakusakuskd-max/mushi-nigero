# むしから にげろ！（WebXR ステルスゲーム）

むしに みつからないように、きいろい ひかりの ゴールまで いくゲーム。

## ファイル
| ファイル | なかみ |
|---|---|
| `settings.js` | **ここを いじって あそぼう！** むしの かず・はやさ・みえる きょり など |
| `game.js` | ゲームの ほんたい |
| `index.html` | さいしょの がめん |

## パソコンで あそぶ
このフォルダで サーバーを うごかして、ブラウザで http://localhost:8000 を ひらく。

```bash
python3 -m http.server 8000
```

## Questで あそぶ
WebXRは **https の サイト**（または localhost）でしか うごかない。かんたんな ほうほうは 2つ。

1. **GitHub Pages に おく（おすすめ）**：このフォルダを GitHub に のせて Pages を オンにすると、`https://〜.github.io/〜/` で ひらける。Questの ブラウザで その URL を ひらいて「ENTER VR」。
2. **USBケーブルで つなぐ**：Questを 開発者モードに して、パソコンで `adb reverse tcp:8000 tcp:8000` を じっこう。Questの ブラウザで http://localhost:8000 を ひらく。

## むしの うごき
みまわり →（あやしい）→ ？けいかい →（はっきり みえた）→ ！おいかける →（みうしなう）→ さがす →（あきらめる）→ みまわり

- しげみの なかで しゃがむと ほとんど みつからない
- 岩や 木の うしろは みえない
- はしると 足音で きづかれる
- 1ぴきに みつかると ちかくの なかまも よってくる
